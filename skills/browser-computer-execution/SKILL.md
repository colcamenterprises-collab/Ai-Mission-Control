# Browser and Computer Execution

Use this skill when an assigned outcome requires interacting with a web application or graphical computer interface.

## Operating loop

PLAN → ACT → OBSERVE → VERIFY → CORRECT → REPORT.

- Use the authenticated company browser/computer capability already granted to the Work Request.
- Keep execution inside the named project, account, environment and acceptance criteria.
- Capture evidence of the resulting state, not merely evidence that a click or command ran.
- Retry recoverable UI failures within a bounded loop; report a blocker instead of guessing.
- Never bypass authentication, permission, approval, security, spend or external-commitment controls.
- Draft, preview, inspect and test autonomously when the execution contract permits it.
- Production changes, destructive actions, financial commitments and consequential external publication remain governed by Mission Control approval policy.

## Completion evidence

Return the target, actions performed, final observed state, verification performed, evidence locations/IDs, exceptions, and any protected next action requiring approval.

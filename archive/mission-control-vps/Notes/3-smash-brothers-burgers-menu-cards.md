# Smash Brothers Burgers - Menu Cards

- Develop a menu playbook with recipes (quantities, ingredients, picture) in A5 size or allow A4 size document that holds 3 menu items. The document can be laminated and placed around the different sections so staff understand what is required for each menu item and how each of those items look when completed.
- Styled - One generic styling that is simple to replicate and eventually be able to be dragged in to v3.0 as an upsell opportunity
- Smaller version individual recipe cards that can be produced independently

# Mission Control Visual Product Reset

## Product aim

Mission Control is a central place for a business to create, manage, and review AI workers that complete real work on behalf of the company.

A customer might be a restaurant, plumber, agency, real-estate company, software team, or any other business. The surface must not feel like a developer dashboard.

## Core jobs

- Capture work that needs doing.
- Assign work to people or AI workers.
- Manage AI workers from different providers such as Claude, OpenAI, Clawbot, Hermes, Goose, Codex, Gemini, and future providers.
- Set recurring work and reporting.
- Show what was done, what is waiting, and what needs attention.
- Keep business knowledge, playbooks, contacts, marketing, planner items, and reports in one visual control room.

## Design direction

The product must be:

- Minimal.
- Premium.
- Visual-first.
- Plain-English.
- Low word count.
- Consistent.
- Business-owner friendly.

The interface should feel closer to a high-end operations dashboard than a technical admin panel.

## Language rules

Avoid technical or robotic labels on the main surface.

Do not use typewriter/mono styling for normal UI labels.
Do not overuse uppercase tracking.
Do not stack header, subheader, caption, eyebrow, and helper copy in the same area.
Do not show long instruction copy unless the user opens details.

Use short labels:

- Overview
- Work
- AI Team
- Knowledge
- Playbooks
- Marketing
- Planner
- Contacts
- Reports
- Setup

## Visual rules

- One font family across the visible business UI.
- One card system.
- One nav system.
- One set of spacing and radius rules.
- No sci-fi orbit as the main hero.
- No fake logo mark.
- No boxed logo.
- No oversized text wall.
- No dense developer surface on the default dashboard.

## Dashboard target

The Overview page should show:

- A concise header.
- One primary action: Add work.
- One secondary action: Employ AI worker.
- A compact metric row.
- A visual work board / activity area.
- An AI Team panel.
- A reports panel.

The user should understand the screen in under five seconds.

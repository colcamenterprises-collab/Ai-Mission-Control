Current assigned role: `agents/roles/mission-control-lead`

## Replacement procedure

1. Create a new agent profile, for example `agents/profiles/jim/`.
2. Assign the new profile to the stable Mission Control Lead role.
3. Preserve Mission Brain memory, skills, projects and execution history unchanged.
4. Migrate only explicitly approved agent-specific learning.
5. Reissue runtime credentials and grants to the new agent rather than copying secrets from the previous profile.
6. Verify the replacement can read required shared context before deactivating the previous agent.
